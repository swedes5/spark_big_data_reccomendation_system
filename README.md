# Yelp Stars Predictor Using Recommendation System
A hybrid recommendation system using the Python pyspark library alongside NLP sentiment analysis and traditional recommendation system techniques.

Future Work:
The base work has been completed and the ratings have been predicted.  To actually recommend restaurants to a user would be the true recommendation system in my opinion.  Some thoughts I have about that from searching for restaurants myself are:
  - choose best rated restaurants in a location and recommend a top N of them.
  - choose top rated restaurants based on cuisine and recommend a top N of them.
  - implement a random top 1 or top N selection that all surpass a ratings threshold to allow for more fun and spontaneous experience for the users.
